# BSR自動記録バッチ — セットアップ

`packages/bsr` にあるバッチの手順書です。画面はありません。**毎日1回、指定した
Googleスプレッドシートに Amazon の売れ筋ランキング（BSR）を自動で書き込みます。**

- **費用**: かかりません。SP-API も Google Sheets API も、この規模なら無料枠内です。
  （Amazonは2025年11月にSP-APIの有料化を発表しましたが、**2026年5月12日に撤回**されています）
- **前提**: 自社のAmazonセラーアカウント（セラーセントラル）とGoogleアカウント。
- **取れるもの**: 大カテゴリのBSR、サブカテゴリのBSR。
  **過去に遡ることはできません**（設定した日から先の分が貯まっていきます）。

---

## シートの形

こういう形のシートに書き込みます。**ASINは自分で1行目に入れてください**。
そこがそのまま「追跡対象リスト」になります。

|   | A | B | C | D | E |
|---|---|---|---|---|---|
| **1** | | `B0ABC12345` | | `B0XYZ98765` | |
| **2** | 日付 | 大カテゴリ | サブ | 大カテゴリ | サブ |
| **3** | 2026-09-10 | 333 | 1 | 1,717 | 12 |
| **4** | 2026-09-11 | 405 | 1 | 1,321 | 13 |

- **1行目**: B列から**2列おき**にASIN（B, D, F, H…）。間のC, E, G列は空のままにしてください
- **2行目**: 見出し。空ならバッチが初回に自動で入れます
- **3行目以降**: A列に日付、その行に各ASINのBSRが入ります。1日1行ずつ下に増えます

ASINを増やしたいときは、**1行目の右端に2列おきで足すだけ**です。バッチが次回から拾います。
やめたいときはそのASINのセルを消してください（過去のデータは残ります）。

> 行や列の開始位置は `.env` で変えられます（`SHEET_ASIN_ROW` など）。既存シートの
> 途中から始めたい場合に使ってください。既定のままなら設定不要です。

## 1. Amazon側の準備（開発者登録・審査あり）

セラーセントラルの「アプリとサービス」→「開発者セントラル」から開発者プロフィールを登録します。
セキュリティに関する質問票への回答が必要で、**承認まで数日〜数週間かかります**。

1. 開発者プロフィールを登録（ロールは **Product Listing**）
2. 承認後、「アプリを追加」で**プライベートアプリ**を作成 → **LWAクライアントID / シークレット** が発行される
3. アプリ一覧の「認可」→ **セルフオーソライズ** で **リフレッシュトークン**（`Atzr|…`）を発行

> ロールを後から追加した場合は、**リフレッシュトークンを取り直す必要があります**。
> 古いトークンには古いロールしか紐付いておらず、403エラーになります。

## 2. Google側の準備（サービスアカウント）

シートに書き込むための「ロボット用アカウント」を作ります。個人のGoogleアカウントで
ログインさせる必要はありません（パソコンが無人でも動かせます）。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作る（既存でも可）
2. 「APIとサービス」→「ライブラリ」で **Google Sheets API** を有効化
3. 「認証情報」→「認証情報を作成」→ **サービスアカウント** を作成
4. 作ったサービスアカウント →「キー」タブ →「鍵を追加」→ **JSON** をダウンロード
5. そのJSONを `packages/bsr/google-service-account.json` として保存
   （`.gitignore` 済み。**絶対にコミットしないでください**）
6. **書き込み先のスプレッドシートを開き、サービスアカウントのメールアドレス
   （`...@....iam.gserviceaccount.com`）に「編集者」として共有**

手順6を忘れると 403 になります。エラーメッセージに共有すべきアドレスが出るので、
分からなくなったらバッチを1回動かして確認してください。

## 3. .env に設定する

`packages/bsr/.env` を編集します（`.env.example` が雛形です）。

```
GOOGLE_SERVICE_ACCOUNT_KEY_FILE="./google-service-account.json"
SPREADSHEET_ID=1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890
SHEET_NAME="BSR"

SPAPI_LWA_CLIENT_ID=amzn1.application-oa2-client.xxxxxxxx
SPAPI_LWA_CLIENT_SECRET=amzn1.oa2-cs.v1.xxxxxxxx
SPAPI_REFRESH_TOKEN=Atzr|xxxxxxxx

BSR_MARKETPLACE="JP"
BSR_TIMEZONE="Asia/Tokyo"
```

`SPREADSHEET_ID` はシートのURLの `/d/` と `/edit` の間の文字列です。

```
https://docs.google.com/spreadsheets/d/★この部分★/edit#gid=0
```

## 4. 動作確認

まず書き込みなしの確認から。設定とシートの読み取りだけを試します。

```bash
npm run bsr:check
```

シート名と、拾えたASINの一覧が出れば設定は正しくできています。問題なければ本番実行。

```bash
npm run bsr:collect
```

## 毎日自動で実行する（Windowsタスクスケジューラ）

実行用のバッチファイル `packages/bsr/bsr-daily.bat` を用意してあります。
タスクスケジューラにはこれ1つを指定してください。

1. タスクスケジューラを開き「基本タスクの作成」
2. トリガー: 毎日 5:00 など
3. 操作: プログラムの開始
   - プログラム: `C:\Users\pc424\Documents\apps\ec-ai\packages\bsr\bsr-daily.bat`
   - **引数・開始場所は空のまま**（バッチが自分で自分の場所に移動します）
4. 作成後、タスクのプロパティで「スリープを解除して実行」を有効にすると取りこぼしが減ります

> `npm.cmd` を直接指定すると、`C:\Program Files` のスペースで引数が切れて
> 「引数が[プログラム]ボックスに含まれているように見えます」という警告が出ます。
> バッチファイル経由ならこれを避けられます。

実行結果は `packages/bsr/logs/bsr.log` に追記されます。動かないときはまずここを見てください。

### バッチファイルを編集するときの注意

`bsr-daily.bat` は **Shift_JIS・改行CRLF** で保存されています。UTF-8やLF改行で保存し直すと、
cmdが日本語のコメント行を解釈できずエラーになります。エディタで開くときは文字コードに注意してください。

**パソコンが起動していない時間は実行されません。** その日ぶんが抜けた場合、あとから
埋めることはできません（Amazonが過去の順位を返さないため）。取りこぼしを避けたい場合は、
常時起動しているPCやサーバーにタスクを置いてください。

## 仕様のメモ

- **1日1行・冪等**: 同じ日に何度実行しても行は増えません。すでに値が入っているASINは
  APIを叩かずスキップします。上書きしたいときは `-- --force` を付けてください。
- **書き込みは一括**: 全ASINぶんの値を集めてから1回のAPI呼び出しで書きます。
  途中で失敗しても、シートが半端な状態になりにくくしてあります。
- **取得できなかったASIN**: そのセルは空のまま残り、ログに理由が出ます。
  終了コードが `1` になるので、タスクスケジューラ側で失敗を検知できます。
- **日付の照合**: シートの日付はスプレッドシート内部のシリアル値で比較しています。
  表示書式が `2026/09/10` でも `2026-09-10` でも正しく同じ日と判定します。
- **レート制限**: `getCatalogItem` は 2リクエスト/秒 なので、1件あたり0.7秒あけて順番に
  叩きます。100ASINで約70秒です。429が返ったら指数バックオフで3回まで再試行します。
- **サブカテゴリBSR**: Amazonは複数のサブカテゴリランクを返すことがあるため、
  **最も順位の良いもの**を採用しています。
- **依存パッケージはdotenvだけ**: SP-APIのLWA認証もGoogleのサービスアカウント認証も
  自前実装です（`aws-sdk` や `googleapis` は入れていません）。

## よくあるエラー

| 症状 | 原因と対処 |
| --- | --- |
| `スプレッドシートへのアクセスが拒否されました (403)` | シートをサービスアカウントに共有していない。エラーに出るアドレスに「編集者」で共有する |
| `スプレッドシートが見つかりません (404)` | `SPREADSHEET_ID` の転記ミス |
| `シート「BSR」が見つかりません` | タブ名と `SHEET_NAME` が違う |
| `追跡対象のASINが1件もありません` | 1行目B列から2列おきにASINが入っているか確認 |
| `ASINとして読めないセルを飛ばしました` | 1行目のその位置に、ASIN以外の文字が入っている |
| SP-APIの `403` | ロール不足。Product Listing を申請 → 承認後に**リフレッシュトークンを取り直す** |
| `カタログに見つかりません` | ASINの打ち間違い、またはそのマーケットプレイスに存在しないASIN |
| ランキング情報が返らない | ランキング圏外の可能性。セルは空のままになります |
